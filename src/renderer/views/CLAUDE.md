markdown-view.ts: 保存与冲突恢复委托 core/window-save，失败拒绝切文件与关闭。目标读取成功才接管文件，读失败保留来源正文；冷开错误路径独立序列化且不授予保存权限，重试复原编辑容器。 MarkdownView。onFocus 区分阅读容器与 CodeMirror，恢复实际焦点。底部反链绑定当前笔记；视图头不注入默认应用按钮。换文件先保存，删除后复用视图根。首次加载即同步 source/live/preview DOM 三态、inline-title 改名（元素挂在编辑器 .cm-sizer 内）、行宽 class（is-readable-line-width）挂 source/reading 视图元素并随设置联动、150ms 防抖自动保存（外部修改同步：先按“发起读取时的文件路径”守卫，读期间切文件即丢弃迟到内容，防跨文件内容污染；再用 _loadedText 判别自家写入的迟到通知，绝不回滚在编辑的文档；save 仅更新仍在编辑文件的 _loadedText）、编辑器右键菜单挂载（捕获阶段记录右键前选区，contextmenu 落点在选区内时恢复，防 CM6 折叠选区）、subpath/line 滚动（标题与块引用 #^id 支持，同步光标与居中）、view-actions 菜单、重命名/换文件后回填视图头面包屑（_updateTitles）。 视图头模式钮按原版 1.14.4：图标表示「点它会切到哪个视图」（编辑视图 lucide-book-open / 阅读视图 lucide-edit-3），aria-label 三行（状态句 + 动作句 + ⌘+单击在新标签页打开），模式切换后同步动作；Mod/中键在右侧叶子打开相反模式，来源模式不变。

settings-view.ts: SettingsHost(app.setting 的实现) + installSettingsHost(app)。克隆原版 fte 宿主：两组导航(options/core，社区组随第三方插件整体移除)、navEl、openTab/closeActiveTab/openTabById/openPluginOptions/updateModalTitle、PluginSettingTab 兼容层(addSettingTab/removePluginTabs 挂载点)。内置页签注册顺序：关于 → 外观 → 界面 → 编辑器 → 文件与链接 → 快捷键 → 核心插件。核心插件页签在宿主构造与每次 openInApp 时按「已启用且导出 settingTab」全量登记进 core 分组（ensureCorePluginTab；registerCorePluginTabs 幂等），插件启停时同步增删——对齐原版 1.14.4，未点齿轮也能在左栏看到插件设置页。侧栏顶部为全局搜索框 .setting-search-container（跨页签索引：采集各页签 .setting-item 的名称、描述与别名，别名由 setSettingAliases 挂在行的 data-aliases 上；从未渲染过的页签离屏渲染一次并缓存；匹配器与原版 loe.search 一致：查询按空格切词、每词必须是子串，name/desc/aliases 三路取最高分，只有名称命中才包 suggestion-highlight，描述或别名命中的行显示不带高亮的名称；结果按页签分组、命中用 suggestion-highlight、每组只显前 3 条 + 「还有 N 个」、点击开页签并 scrollIntoView + is-flashing 750ms、空态 .setting-search-empty、清空恢复分组）+ 可导航子页面机制 openPage/closePage（.setting-page 标题栏/内容，CSS 片段与字体等子页共用）。1.14.4 popout：shouldUsePopout/getPopoutOptions/getRootEl 与原版同名同行，独立窗口内 modalEl 直挂 body(is-popout-modal)；is-popout-modal 生效后重算 macOS 红绿灯（32px → 10,8）。

graph-view.ts: 全局/局部图视图生命周期。跟随文件变化，关闭时清理引擎和渲染器。
graph-renderer.ts: 画布绘制、命中、拖拽和平移。设备像素统一换算，销毁释放监听、帧、触摸控制器与力学 worker；worker 后端由 sim.onUpdate → changed() 驱动重绘，本地回退才在帧回调里 tick()。命中半径按原版 = 节点半径（桌面，setHitScale(1)），移动端规则保留 5 倍命中区（setHitScale(5)，原版 isMobile 才画 r=500 的透明圆），取消高亮的 +2 容差仍保留。
graph-touch.ts: 图谱触屏/触控笔控制器。单指拖节点、空白拖动平移、双指捏合缩放，轻点打开节点；与鼠标路径共用 renderer 的坐标与节点命中，销毁时解除全部 pointer/touch 监听。
canvas-view.ts: 保存委托 core/window-save，CAS 失败保留节点及原文。读取与JSON结构校验成功才接管目标；失败保留来源卡片，冷开错误路径独立序列化且不授予保存权限，重试复原画布容器。 画布装配。节点构造委托 canvas-node-factory。观察挂载尺寸，防抖保存，切换文件前落盘，关闭后释放帧与节点。vault modify 的外部修改按磁盘内容重载并保留视口，自身写入按 _savedText 过滤 watcher 回声；rename/delete 事件驱动分组背景路径迁移或清空（setBackgroundPath）。撤销/重做：requestSave 防抖推进全量快照历史（上限 100），applyHistory 经 importData 差量重建且不产生新条目；控件组含快速设置（对齐网格/对齐物体/只读）与撤销/重做按钮。选择浮动工具条由 buildCanvasMenu 建立为 this.menu，帧尾按选择/视口/被拖元素的变化重绘，拖动期间隐藏。选择差异经 applySelectionDiff 统一落到焦点与高亮（单选只置聚焦、多选只置高亮）。getData 按 z 升序写出节点、importData 读到较低 z 时重新置顶、cloneData 为克隆拖动换新 id、canSnap 决定拖动是否吸附与画参考线。只读标记按原版 localDataManager 存 localStorage('canvas-<路径>')，重命名迁移、删除清理，初次装载恢复；切换只读时逐节点通知正文（onReadonlyChange，文本卡片立即退出编辑）。导出图片在本类暴露 renderCanvasImage(可测试)、generateHDImage(命令/面板菜单入口)与 promptImageSavePath(保存对话框，验收替换它即可跳过原生对话框)；saveCanvasImage 委托 canvas-export-tiles 捕获整窗并合成，选项弹窗在 canvas-export-dialog.ts；视图头经共用菜单链，onPaneMenu 追加真实导出。控件与建卡菜单的 DOM 构建在 canvas-controls.ts。剪贴板与拖入：wrapper 的 copy/cut/paste 交给 canvas-clipboard.ts，文件树/系统文件/URL/文本 drop 交给 canvas-drop.ts。
canvas-selection.ts: 画布选择框（原版 V3）。同一个类承担两种角色：空白拖动时作框选矩形（无 mod 类、指针穿透），多选时作 .mod-group-selection 包围盒（可拖拽、可缩放、带 8 个 data-resize 手柄）。update 把 bbox 外扩 10px 后定位，容器首次使用时挂到 .canvas；手柄拖动按各元素在框内的相对位置整体等比缩放，受 minContainerDimension 约束，吸附复用视口层 A3/L3 并画参考线，松手一次性写盘。只对 CanvasNode 生效：边不参与缩放。
canvas-arrange.ts: 画布选择浮动工具条（原版 q3）与排布运算。buildCanvasMenu 建 .canvas-menu-container > .canvas-menu，按钮按选中内容给：移除、设置颜色（canvas-submenu 取色器与自定义色输入）、聚焦当前卡片（恒显）、创建分组、排布菜单；2+ 选中时工具条持有 .mod-group-selection 包围盒，右键转选择菜单。排布运算是纯函数：alignTargets 取排布对象（单选分组时取组内节点与内缩 20 的组框），对齐 6 向落到并集边界，分布按元素尺寸平分剩余空隙（首尾不动），拉伸把每个元素拉满并集整幅，网格排列先按 y 重叠切行再行内按 x 铺开。按钮与只读显隐逐条对齐原版。
canvas-controls.ts: 画布控件层（从 canvas-view 拆出）。buildCardMenu 建右下角「新建卡片/笔记/媒体」按钮（点击在视口中心建，拖拽拖出尺寸）；buildControls 建右上角四组控件（原版 app.css 18345：inset-inline-end + top）：快速设置（只读时点击直接退出只读，否则弹 showQuickSettingsMenu）、缩放四键、撤销/重做、帮助。状态归 canvas-view：cardMenuEl/canvasControlsEl/quickSettingsButton/undoBtnEl/redoBtnEl 由本层写入宿主。
canvas-clipboard.ts: 画布剪贴板（原版 CanvasView.handleCopy/handleCut/handlePaste）。copy 写入 MIME `obsidian/canvas`，payload 为 `{nodes,edges,center}`，center 取选中并集中心；cut 先 copy 再 deleteSelection；paste 按指针中心与 payload center 偏移，cloneData 换新节点/边 id，importData(prune=false) 后选中新节点。纯文本 URL 建链接卡，其余文本建文本卡；外部剪贴板文件经saveAttachment落库，再按10列建文件卡。
canvas-drop.ts: 画布拖入层（原版 app.dragManager.handleDrop）。内部文件树载荷是 `text/plain` JSON（file/folder/files），递归收集文件后按 10 列、列间 45px 建文件卡；系统 Files 经 saveAttachment 写入附件目录；text/uri-list 或纯文本 URL 建链接卡，其余文本建文本卡。只读画布不接收 drop。
canvas-help.ts: 画布帮助弹窗（原版 c3）。左下控件第四组 help 按钮打开本弹窗；行结构 .canvas-help > .canvas-instruction（标签 + .canvas-instruction-desc 里的 .setting-hotkey 组合键）；组合键按平台拼接（macOS 用 ⌘⇧⌥⌃ 不加分隔符，其他平台 Ctrl/Shift/Alt + 号连接）；默认滚轮行为为滚动平移，「移动白板」= Space+拖动/滚动、「缩放」= Mod+滚动/Space+滚动，插件选项 defaultWheelBehavior=zoom 时两者互换。
diff-view.ts: renderDiffView(prev,next)。行级 LCS 对齐，删除/插入按块配对，行内差异标 diff-changed；相等行按原版阈值折叠(N lines folded 可点击展开)。供文件恢复弹窗"显示差异"。
canvas-viewport.ts: 画布坐标与缩放。限制缩放目标，按缩放挂载正文，收敛后停止帧。帧内把移动节点的关联边一并加入重绘集合，帧尾应用选择差异（applySelectionDiff）并在选择/视口/被拖元素变化时重绘浮动工具条。含物体对齐 getSnapping：候选框取「4 角 + 中心」5 点，逐轴取最近对齐值并返回位移，同时把匹配点画进 svg.canvas-snaps（原版 D3/A3/L3 的参考线）；clearSnapPoints 每次 move 先清，endSnapPointRendering 在 drag 收尾摘除容器；并导出 A3/L3 两个吸附点工具供多选包围盒缩放复用。snapToObjects=false 时不吸附也不画线；候选取全部节点而非视口内节点。markDirty 在被选元素变脏时标记选择变化，取色器实时改色据此重绘工具条。
canvas-interactions.ts: 指针、滚轮、框选、键盘与选择交互；拖拽原语委托 canvas-drag，保留旧导出。含选择集合语义（select/deselect/toggleSelect/selectOnly/selectAll/deselectAll/updateSelection/applySelectionDiff/deleteSelection）。所有选择改动先拍旧集合再置 selectionChanged，焦点与高亮的进出留到帧尾统一应用，1↔多选切换不会留下「既聚焦又选中」的中间态。键盘含 Escape/Delete、Mod+A 全选、Mod+Z/Mod+Shift+Z/Mod+Y 撤销重做、Shift+1/2 缩放、方向键微移选中节点（Shift 5 倍、对齐网格时吸附），焦点在输入控件内不抢按键；背景与节点 pointerdown 聚焦 wrapper，复制/剪切/Delete 等键盘语义直接命中画布；背景右键菜单追加撤销/重做。空白/节点上右键（macOS Ctrl+左键）或中键拖动超过 5px 才进入平移，未超阈值保留右键菜单；macOS 先到的 contextmenu 在进入拖动时主动关闭，Windows 在 pointerup 后补发的 contextmenu 用一次性捕获监听吞掉。拖动选中集合逐帧调用 getSnapping 得到吸附位移与参考线，候选剔除被拖节点且分组只与分组对齐，被其他被拖分组完整包含的分组不参与吸附；mac 按住 Alt（其他平台 Ctrl）拖动改为克隆：原件归位、替身随笔移动，松手 cloneData + importData 生成新节点并选中。框选用 .canvas-selection 矩形，分组需被完整包含，Shift 与已有选择异或；松手按住 Mod 时按 defaultModDragBehavior 建卡或弹建卡菜单。参考线由 handleDragWithPan 的 cleanup 清除。几何结果交给视图保存。临时节点（虚影）与临时边一律在**拖拽真正开始**（越过阈值）时才建（handleDragWithPan 的 handlers.start，对齐原版把临时节点建在拖拽工厂里），纯点击不建、拖拽收尾必清，避免画布上残留 accent 描边的 .is-dummy 蓝框并挡住后续拖拽。
canvas-history.ts: CanvasHistory 有界快照栈（push 截断重做尾部、超限丢最旧、replace/clear）。撤销/重做的存储层，条目为 getData() 全量对象。
canvas-node.ts: hasCanvasEditor 校验编辑宿主并保留节点身份。节点基类与正文容器层（文本卡片见 canvas-text-node.ts，链接见 canvas-link-node.ts，分组见 canvas-group-node.ts）。CanvasNode 负责几何、选择态、指针/缩放入口与菜单，setColor 把自定义色归一化为 "r,g,b" 供取色器调用；CanvasContentNode 提供 contentEl + blocker + placeholder 机制（交互控件上的指针不进入编辑）。8 个 resizer 与嵌在边手柄内的连接点就近挂在 nodeEl 上（原版在 canvas-node-interaction-layer），用 mod-handles 承接同一显隐语义；parkEditorSelection 把只读 CM6 光标停到无 markdown 记号的行，未编辑卡片不露 # 与列表符号。连线手柄的临时虚影与临时边同样在拖拽真正开始时才建，纯点击不残留。
canvas-text-node.ts: 文本卡片（从 canvas-node.ts 拆出）。正文是内嵌 CM6 实时预览编辑器（原版 P5 + L5），DOM 为 contentEl.markdown-embed > .markdown-embed-content > .markdown-source-view（原版跑在内嵌 iframe，本复刻内联）。编辑器随 mountContent/unmountContent 创建与 destroy，只活在挂载期间；仅编辑态可写，未编辑时 blocker 挡住指针（卡片照常拖拽/选中）；双击与单击已聚焦卡片进编辑，Escape/Mod+Enter 退出。正文变化经 markDirty/requestSave 落盘并进入撤销快照；editorEl.value 兼容旧 textarea 句柄读写正文。菜单追加编辑与转换为文件。活动编辑器登记：getActiveEditorHost 返回自身（形状 { editor, file, containerEl }，getMode 为 source、file 为画布文件），focus/startEditing 登记，stopEditing/blur/卸载编辑器/销毁清空，命令层由此把 editor:* 作用在卡片正文。
canvas-link-node.ts: 链接卡片（从 canvas-node.ts 拆出）。正文是 webview.canvas-link（Electron webviewTag 可用时；否则同尺寸 iframe）内嵌网页，contentBlocker 在未聚焦时拦截指针、聚焦后点击交给网页；网页标题经 page-title-updated 回写卡片标签，未到达前显示 URL。normalizeLinkUrl 先做媒体地址归一化；桌面 webview 固定 partition 'persist:vault-'+vaultId，仅 releases.obsidian.md/youtube 按原版保留默认 UA。失败时显示错误占位（URL/描述/重试），重试复位 frameError 并重载；alwaysKeepLoaded：缩到断点以下不卸载网页。captureFrameImage 用 webview.capturePage() 取真实画面，iframe 回退/失败态返回 null，导出回退 URL 文本。菜单含换网址/在浏览器打开/复制网址/重新加载（http(s) 才显示重载）。卡片外标签 Mod 单击或双击在新窗口打开。
canvas-group-node.ts: 分组节点（从 canvas-node.ts 拆出）。圆角矩形 + 顶部 contenteditable 标签，永远铺在底层：z 取 -宽*高（原版 F5），面积越大越靠后，且不参与单选的临时置顶；标签编辑只改标签，几何与写盘由 canvas-view 调度；分组菜单含「编辑文字」与背景图操作（set/replace/remove + cover/ratio/repeat 勾选）。bgPath 是渲染、比例与导出的唯一来源，bgFile 仅为 vault 索引缓存；setBackgroundPath 供 rename/delete 生命周期替换或清空路径，保留样式，删除时移除内容与 backgroundStyle；backgroundStyle 默认 cover；cover/repeat 写 contentEl 内联背景，ratio 读取图片真实宽高比后用 resize 收成同比例。标签前景色按分组色亮度阈值 150 切 mod-foreground-light/dark（原版 iT）。
canvas-local-data.ts: 画布本地数据（原版 localDataManager 等价物）。localStorage key 'canvas-<路径>' 存 {readonly:true}；load/save/migrate/drop，供视图与快速设置菜单调用。
canvas-file-node.ts: 文件卡片（从 canvas-node.ts 拆出）。md 卡渲染正文（正文前带 inline title 文件名，对齐原版 .markdown-preview-sizer 首个 .mod-header.mod-ui > .inline-title）、.canvas 卡渲染缩略图（canvas-minimap.ts，不再把原始 JSON 当 markdown）、图片/音视频直显、其余占位；缺失文件标签是警告图标 + 路径。md 卡双击进入卡片内 CM6 编辑，已聚焦后单击正文同样进入（原版 hg 语义）；输入 400ms 防抖写回真实文件，Escape/Mod+Enter/失焦退出并用同一份正文明刻恢复预览；编辑期间登记为活动编辑器（file 为被编辑笔记）。挂载前对 contentEl 判空。
canvas-options.ts: 画布选项单一来源。DEFAULT_CANVAS_OPTIONS、读写 .obsidian/canvas.json（loadOptions/saveOptions）、applyCanvasOptions 把改动灌回已打开的视图（对齐原版 rerenderCanvases）；新白板位置按 root/current/folder 解析目录。
canvas-minimap.ts: CanvasEmbedOptions 与 CanvasEmbedMarker 约束异步占位。画布文件缩略图与画布嵌入层（移植原版 lte / cte）。renderCanvasMinimap 把 .canvas JSON 画成缩略图 SVG（.canvas-minimap）：分组与卡片画成 rx/ry=20 圆角矩形（先分组后卡片），边画贝塞尔路径（线宽 sqrt((maxX-minX)/10)），viewBox 取内容并集外扩 5%；复用 sidePoint/bezierFor/unionBBox/expandBBox/applyCanvasColor。createCanvasEmbed/createCanvasEmbedWidget/mountCanvasEmbed 负责行内画布嵌入（原版 inline-embed 形态：图标 + 文件名标题 + 缩略图，限高 --embed-canvas-max-height），供 markdown/reading.ts 与 editor/live-preview.ts 使用。
canvas-edge.ts: 连线与标签几何。拖动连接点吸附节点并保存端点；点击边选中同时聚焦 wrapper，保持复制/Delete 等键盘语义作用在画布。拖边端点改接别处时，临时虚影与临时边在**拖拽真正开始**时才建（原版 oM 工厂语义），纯点击不残留。
canvas-menu.ts: 视图头动作委托共用原生按钮，导出参与文件面板菜单链。 文件、链接、分组选择与画布上下文菜单。快速设置菜单三项：对齐网格/对齐物体/只读。另含视图面板菜单 showCanvasPaneMenu（action 段「导出图片」）与 installCanvasViewActions（委托共用原生动作按钮，导出参与完整文件菜单）。
canvas-utils.ts: 无状态几何、颜色与多值索引。供节点、边、视口与选择框共用；rectFromBBox 把 bbox 折成矩形。
canvas-export.ts: 几何、选项与保存编排。真实落盘走整窗分块；取消不截图，失败不写图。同步 renderCanvasImage 仅为简化预览；上限 16284，密度按原版取整；视口忽略隐藏的缩放值。
canvas-export-dialog.ts: 导出图片设置弹窗（原版 generateHDImage 第一步）。.modal.mod-narrow 内 p.u-muted 描述 + 四个 Setting：范围下拉(整个白板/仅当前部分)、缩放滑杆(log2 值，getValuePretty 显示倍率，描述显示预计尺寸)、显示水印(默认开)、隐私模式(默认关)；范围选「仅当前部分」时缩放与水印设置隐藏。不渲染图像、不碰磁盘，数值经构造参数注入（dimensionsFor/onSave），回报 { frame, scale?, showLogo, privacyMode }；仅全图回报 scale。
