# src/renderer/views/

> L2 | 父级: /src/renderer/CLAUDE.md

内置视图。视图必须遵守 core/view.js 契约：构造只存 leaf，DOM 在 onOpen 建立到 this.contentEl(=view._rootEl)。

成员清单
index.js: registerBuiltinViews(app)。注册 empty/markdown/image/video/audio/pdf，附带扩展名提示；安装 settings host。
markdown-view.js: MarkdownView。换文件先保存，删除后复用视图根。首次加载即同步 source/live/preview DOM 三态、inline-title 改名（元素挂在编辑器 .cm-sizer 内）、行宽 class（is-readable-line-width）挂 source/reading 视图元素并随设置联动、150ms 防抖自动保存（外部修改同步：先按“发起读取时的文件路径”守卫，读期间切文件即丢弃迟到内容，防跨文件内容污染；再用 _loadedText 判别自家写入的迟到通知，绝不回滚在编辑的文档；save 仅更新仍在编辑文件的 _loadedText）、编辑器右键菜单挂载、subpath/line 滚动、view-actions 菜单、重命名/换文件后回填视图头面包屑（_updateTitles）。
empty-view.js: EmptyView。空标签页动作列表逐条对齐 1.14.4：三枚等宽 text-icon-button.mod-pill（新建笔记 lucide-square-pen + 热键 / 新建白板 lucide-layout-dashboard / 打开文件 lucide-search + 热键）；库为空时不显示「打开文件」，无「关闭」项。
media-view.js: MediaView 及 ImageView/VideoView/AudioView/PdfView。经 adapter.getResourcePath() 取 app:// 文件 URL。
settings-view.js: SettingsHost(app.setting 的实现) + installSettingsHost(app)。克隆原版 fte 宿主：两组导航(options/core，社区组随第三方插件整体移除)、navEl、openTab/closeActiveTab/openTabById/openPluginOptions/updateModalTitle、PluginSettingTab 兼容层(addSettingTab/removePluginTabs 挂载点)。侧栏布局设置弹窗。1.14.4 popout：shouldUsePopout/getPopoutOptions/getRootEl 与原版同名同行，独立窗口内 modalEl 直挂 body(is-popout-modal)。
settings-tabs.js: AboutTab/EditorTab/FileTab 三个内置页签 + VimTestModal(输入 :q 验证)/ExcludedFilesModal(忽略文件管理)。对齐原版 O7/nte/lte 行结构与顺序；配置写 app.settings.updateAppSettings。
settings-tabs-appearance.js: AppearanceTab + FontManagerModal。对齐原版 Jee：基础颜色/主题色/主题/界面(含「在窗口中打开设置」开关，写 settingsPopoutWindow)/字体/高级(缩放·原生菜单·窗口边框·硬件加速)/CSS 代码片段；CSS 注入由 app._applyCustomCss 执行。
settings-tabs-plugins.js: HotkeysTab + HotkeyRecorderModal(按键录制)、CorePluginsTab。快捷键页对齐原版 w0：工具栏 filter 菜单 + hotkey-filter 芯片承载状态筛选（全部/已分配/由我分配/未分配，选"全部"移除芯片），搜索框右缘 lucide-keyboard 装饰图标进入捕获态按组合键筛选（再次点击或 Esc 退出），冲突芯片带 has-conflict 类、点击清空搜索并按该快捷键筛选；行结构为 setting-command-hotkeys + setting-hotkey(文本+lucide-x)+setting-add/restore-hotkey-button；暴露 setQuery/setHotkeyFilter。核心页对齐 dte：.setting-group-search 裸搜索 + 打开时自动聚焦，齿轮(有 settingTab)/快捷键(有命令)入口仅在启用时显隐，lucide-plus-circle 跳快捷键页并按插件 id 前缀过滤。第三方插件页已整体移除。
graph-view.js: 全局/局部图视图生命周期。跟随文件变化，关闭时清理引擎和渲染器。
graph-renderer.js: 画布绘制、命中、拖拽和平移。设备像素统一换算，销毁释放监听、帧与力学 worker；worker 后端由 sim.onUpdate → changed() 驱动重绘，本地回退才在帧回调里 tick()。
canvas-view.js: 画布装配。观察挂载尺寸，防抖保存，切换文件前落盘，关闭后释放帧与节点。vault modify 的外部修改按磁盘内容重载并保留视口，自身写入按 _savedText 过滤 watcher 回声。撤销/重做：requestSave 防抖推进全量快照历史（上限 100），applyHistory 经 importData 差量重建且不产生新条目；控件组含快速设置（对齐网格/对齐物体/只读）与撤销/重做按钮。选择浮动工具条由 buildCanvasMenu 建立为 this.menu，帧尾按选择/视口/被拖元素的变化重绘，拖动期间隐藏。选择差异经 applySelectionDiff 统一落到焦点与高亮（单选只置聚焦、多选只置高亮）。getData 按 z 升序写出节点、importData 读到较低 z 时重新置顶、cloneData 为克隆拖动换新 id、canSnap 决定拖动是否吸附与画参考线。只读标记按原版 localDataManager 存 localStorage('canvas-<路径>')，重命名迁移、删除清理，初次装载恢复；切换只读时逐节点通知正文（onReadonlyChange，文本卡片立即退出编辑）。导出图片在本类暴露 renderCanvasImage(可测试)、generateHDImage(命令/面板菜单入口)与 promptImageSavePath(保存对话框，验收替换它即可跳过原生对话框)；绘制在 canvas-export.js，选项弹窗在 canvas-export-dialog.js；视图头部经 installCanvasViewActions 增加「更多选项」按钮打开面板菜单。控件与建卡菜单的 DOM 构建在 canvas-controls.js。
canvas-selection.js: 画布选择框（原版 V3）。同一个类承担两种角色：空白拖动时作框选矩形（无 mod 类、指针穿透），多选时作 .mod-group-selection 包围盒（可拖拽、可缩放、带 8 个 data-resize 手柄）。update 把 bbox 外扩 10px 后定位，容器首次使用时挂到 .canvas；手柄拖动按各元素在框内的相对位置整体等比缩放，受 minContainerDimension 约束，吸附复用视口层 A3/L3 并画参考线，松手一次性写盘。只对 CanvasNode 生效：边不参与缩放。
canvas-arrange.js: 画布选择浮动工具条（原版 q3）与排布运算。buildCanvasMenu 建 .canvas-menu-container > .canvas-menu，按钮按选中内容给：移除、设置颜色（canvas-submenu 取色器与自定义色输入）、聚焦当前卡片（恒显）、创建分组、排布菜单；2+ 选中时工具条持有 .mod-group-selection 包围盒，右键转选择菜单。排布运算是纯函数：alignTargets 取排布对象（单选分组时取组内节点与内缩 20 的组框），对齐 6 向落到并集边界，分布按元素尺寸平分剩余空隙（首尾不动），拉伸把每个元素拉满并集整幅，网格排列先按 y 重叠切行再行内按 x 铺开。按钮与只读显隐逐条对齐原版。
canvas-controls.js: 画布控件层（从 canvas-view 拆出）。buildCardMenu 建右下角「新建卡片/笔记/媒体」按钮（点击在视口中心建，拖拽拖出尺寸）；buildControls 建左下角三组控件：快速设置（只读时点击直接退出只读，否则弹 showQuickSettingsMenu）、缩放四键、撤销/重做。状态归 canvas-view：cardMenuEl/canvasControlsEl/quickSettingsButton/undoBtnEl/redoBtnEl 由本层写入宿主。
canvas-help.js: 画布帮助弹窗（原版 c3）。左下控件第四组 help 按钮打开本弹窗；行结构 .canvas-help > .canvas-instruction（标签 + .canvas-instruction-desc 里的 .setting-hotkey 组合键）；组合键按平台拼接（macOS 用 ⌘⇧⌥⌃ 不加分隔符，其他平台 Ctrl/Shift/Alt + 号连接）；默认滚轮行为为滚动平移，「移动白板」= Space+拖动/滚动、「缩放」= Mod+滚动/Space+滚动，插件选项 defaultWheelBehavior=zoom 时两者互换。
diff-view.js: renderDiffView(prev,next)。行级 LCS 对齐，删除/插入按块配对，行内差异标 diff-changed；相等行按原版阈值折叠(N lines folded 可点击展开)。供文件恢复弹窗"显示差异"。
canvas-viewport.js: 画布坐标与缩放。限制缩放目标，按缩放挂载正文，收敛后停止帧。帧内把移动节点的关联边一并加入重绘集合，帧尾应用选择差异（applySelectionDiff）并在选择/视口/被拖元素变化时重绘浮动工具条。含物体对齐 getSnapping：候选框取「4 角 + 中心」5 点，逐轴取最近对齐值并返回位移，同时把匹配点画进 svg.canvas-snaps（原版 D3/A3/L3 的参考线）；clearSnapPoints 每次 move 先清，endSnapPointRendering 在 drag 收尾摘除容器；并导出 A3/L3 两个吸附点工具供多选包围盒缩放复用。snapToObjects=false 时不吸附也不画线；候选取全部节点而非视口内节点。markDirty 在被选元素变脏时标记选择变化，取色器实时改色据此重绘工具条。
canvas-interactions.js: 指针、滚轮、框选、键盘与拖拽原语，以及选择集合语义（select/deselect/toggleSelect/selectOnly/selectAll/deselectAll/updateSelection/applySelectionDiff/deleteSelection）。所有选择改动先拍旧集合再置 selectionChanged，焦点与高亮的进出留到帧尾统一应用，1↔多选切换不会留下「既聚焦又选中」的中间态。键盘含 Escape/Delete、Mod+A 全选、Mod+Z/Mod+Shift+Z/Mod+Y 撤销重做、Shift+1/2 缩放、方向键微移选中节点（Shift 5 倍、对齐网格时吸附），焦点在输入控件内不抢按键；背景右键菜单追加撤销/重做。拖动选中集合逐帧调用 getSnapping 得到吸附位移与参考线，候选剔除被拖节点且分组只与分组对齐，被其他被拖分组完整包含的分组不参与吸附；mac 按住 Alt（其他平台 Ctrl）拖动改为克隆：原件归位、替身随笔移动，松手 cloneData + importData 生成新节点并选中。框选用 .canvas-selection 矩形，分组需被完整包含，Shift 与已有选择异或；松手按住 Mod 时按 defaultModDragBehavior 建卡或弹建卡菜单。参考线由 handleDragWithPan 的 cleanup 清除。几何结果交给视图保存。
canvas-history.js: CanvasHistory 有界快照栈（push 截断重做尾部、超限丢最旧、replace/clear）。撤销/重做的存储层，条目为 getData() 全量对象。
canvas-node.js: 节点基类与正文节点层（分组见 canvas-group-node.js）。CanvasNode 负责几何、选择态、指针/缩放入口与菜单，setColor 把自定义色归一化为 "r,g,b" 供取色器调用；CanvasContentNode 提供 contentEl + blocker + placeholder 机制（交互控件上的指针不进入编辑）。链接节点在此；文本卡片正文见 CanvasTextNode（原版 P5 + L5）：正文是内嵌的 CM6 实时预览编辑器，DOM 为 contentEl.markdown-embed > .markdown-embed-content > .markdown-source-view（原版跑在内嵌 iframe，本复刻内联）。编辑器随 mountContent/unmountContent 创建与 destroy，只活在挂载期间；仅编辑态可写，未编辑时 blocker 挡住指针（卡片照常拖拽/选中）；双击与单击已聚焦卡片进编辑，Escape/Mod+Enter 退出。正文变化经 markDirty/requestSave 落盘并进入撤销快照；editorEl.value 兼容旧 textarea 句柄读写正文。文本卡片菜单追加编辑与转换为文件。活动编辑器登记：有内嵌编辑器的节点 getActiveEditorHost 返回自身（形状 { editor, file, containerEl }，getMode 为 source、file 为画布文件），focus/startEditing 登记，stopEditing/blur/卸载编辑器/销毁清空，命令层由此把 editor:* 作用在卡片正文。
canvas-group-node.js: 分组节点（从 canvas-node.js 拆出）。圆角矩形 + 顶部 contenteditable 标签，永远铺在底层：z 取 -宽*高（原版 F5），面积越大越靠后，且不参与单选的临时置顶；标签编辑只改标签，几何与写盘由 canvas-view 调度；分组菜单在原版基础上追加「编辑文字」（原版 F5.showMenu）。标签前景色按分组色（--canvas-color）亮度切 mod-foreground-light/dark。
canvas-local-data.js: 画布本地数据（原版 localDataManager 等价物）。localStorage key 'canvas-<路径>' 存 {readonly:true}；load/save/migrate/drop，供视图与快速设置菜单调用。
canvas-file-node.js: 文件卡片（从 canvas-node.js 拆出）。md/canvas 渲染预览、图片直显、其余占位；挂载前对 contentEl 判空。
canvas-edge.js: 连线与标签几何。拖动连接点吸附节点并保存端点。
canvas-menu.js: 文件、链接、分组选择与画布上下文菜单。快速设置菜单三项：对齐网格/对齐物体/只读。另含视图面板菜单 showCanvasPaneMenu（action 段「导出图片」）与 installCanvasViewActions（在 .view-actions 建「更多选项」按钮并弹出该菜单）。
canvas-utils.js: 无状态几何、颜色与多值索引。供节点、边、视口与选择框共用；rectFromBBox 把 bbox 折成矩形。
canvas-export.js: 画布图片导出。renderCanvasImage 用离屏 2D canvas 画背景（.canvas-wrapper 计算色）、边（计算描边色 + 贝塞尔 + 箭头）、卡片（计算底色/边框/圆角 + 折行文本，文件卡片为占位矩形 + 文件名），尺寸上限 4096 并等比缩放，返回 {dataURL,width,height,scale}，空画布返回 null。选项逐条对齐原版 generateHDImage：frame full(全画布外扩 100)/viewport(当前视口，倍率取画布缩放且不画水印)、scale 输出倍率、showLogo 左下角应用标记、privacyMode 正文改灰条。canvasExportMetrics 是渲染与弹窗共用的几何（含 maxZoom 与 4096 上限）。exportCanvasImage 是命令与面板菜单入口：空画布提示 → 设置弹窗（取消返回 null）→ saveCanvasImage 经视图 promptImageSavePath 写 PNG 并通知「在访达中显示」。
canvas-export-dialog.js: 导出图片设置弹窗（原版 generateHDImage 第一步）。.modal.mod-narrow 内 p.u-muted 描述 + 四个 Setting：范围下拉(整个白板/仅当前部分)、缩放滑杆(log2 值，getValuePretty 显示倍率，描述显示预计尺寸)、显示水印(默认开)、隐私模式(默认关)；范围选「仅当前部分」时缩放与水印设置隐藏。不渲染图像、不碰磁盘，数值经构造参数注入（dimensionsFor/onSave），回报 { frame, scale, showLogo, privacyMode }。
bookmarks-view.js: 书签树与行内重命名。空分组可见，活动项按文件路径匹配。
slides-presentation.js: SlidesPresentation。全窗口演示宿主（对齐原版 M9：document.body 上的 .slides-container + Escape 关闭；无 reveal.js，分页自有）。按顶层 hr 分页，保留代码围栏和引用内分隔线，每页 renderMarkdown；←/→/点击左右半屏翻页、Esc/关闭按钮销毁覆盖层。演示期间不动底层 markdown 视图，退出后模式、滚动与选区天然保持；导出 splitSlides。
