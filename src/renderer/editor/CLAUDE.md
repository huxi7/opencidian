# src/renderer/editor/

> L2 | 父级: /src/renderer/CLAUDE.md

CodeMirror 6 编辑器层。Editor 类向视图暴露 Obsidian Editor API 子集；live-preview 是唯一的装饰器（表格部件在 table-widget.js）；completions 提供 [[链接]] 数据层，link-suggest 提供单列补全浮窗。

成员清单
editor.js: Editor 包装。构造原版 file layout DOM（.cm-scroller > .cm-sizer > .cm-contentContainer > .cm-gutters + .cm-content，_buildSizerDom；gutter 挂载的 insertBefore 重定向到 contentContainer）。持有 CM6 EditorView 与 _rootEl；暴露 getValue/setValue/getLine/replaceSelection/listSelections/posToOffset 等；updateListener → onChange 回调。setValue 整弹重建 state 并手动 emit change：撤销栈不跨文档边界，装载后 undo 不清空文档、切文件不带回旧文本（插件 ext 扩展经 _baseExtensions 保住）。Compartments：folding(标题与缩进开关)、theme/livePreview/readonly/lineNumbers/wrap/keymap/ext/indent(缩进单位+Tab 宽度,随 useTab/tabSize 热重配)/brackets(自动补全标点,随 autoPairBrackets)。[[ 链接不注册 CM6 autocompletion（不产生 .cm-completionInfo 双列），由 LinkSuggest 接管；setValue 关闭浮窗，destroy 释放监听。setSpellcheck 切换拼写；系统外部文件拖入复制进库并插入嵌入（Alt/Ctrl 直链）；文件树多选载荷 type=files 时按顺序插入全部文件链接；剪贴板图片（截图/图片/HTML data URL）落盘为 Pasted image <时间戳> 并插入嵌入；滚动使用 SelectionRange，setCursor 接受位置对象。
attachments.js: 附件落盘。saveAttachment 按 attachmentFolderPath 选目录、重名追加序号、vault.createBinary 写入；trailing 规则与 pastedImageBaseName 命名；拖入、粘贴与 attach-file 命令共用。
editor-menu.js: 编辑器右键菜单（拼写建议 → 链接 → 剪贴板 → 链接插入 → 文本格式 → 段落设置 → 插入 → 复制路径），先触发 workspace 的 editor-menu 事件再显示；桌面端向主进程申请 context-menu 参数（90ms 超时）。剪贴板启用按 CM 选区经 getRange 判定（原生 editFlags 不含 CM6 选区）；菜单项真实鼠标序列由 menu.js 的子菜单归属规则保证。
live-preview.js: 实时预览装饰层（CM6）。行内 widget（复选框/列表记号/图片/行内数学/水平线/代码块角标/链接与嵌入）已拆到 live-preview-inline-widgets.js；本文件保留块级 widget（属性面板/表格/callout/块级数学/代码块/mermaid，走 StateField，因为 CM6 禁止 ViewPlugin 提供块装饰）与行内装饰构建（buildDecorations/applyInline）。
live-preview-inline-widgets.js: 实时预览的行内 widget 层（从 live-preview.js 拆出，守 800 行上限）。导出 appFacet 与 CheckboxWidget/BulletWidget/ImageWidget/imageWidget/MathWidget/HrWidget/LangWidget/LinkWidget：复选框回写、列表记号（.list-bullet 圆点）、图片（.image-wrapper > img，尺寸语法由 source-text.js 解析）、行内数学、代码块语言角标、链接与 ![[嵌入]]；![[白板.canvas]] 在实时预览按原版 cte 渲染成画布嵌入（容器 + 标题 + 缩略图）。数据库嵌入委托 bases-embed，this 保留宿主文件，# 指定视图；widget 销毁释放订阅。
table-model.js: 表格 Markdown 模型纯函数层。splitRow/parseTableText/serializeTable 对齐原版 getTableString/makeAlignmentRow 口径；cellTextFromInput/cellTextToInput 负责编辑器值 ↔ 文档文本（换行落 <br>、未转义 | 补反斜杠）。不接触 DOM 与 CM6。
table-widget.js: 实时预览表格部件。DOM 为 .cm-table-widget > .table-wrapper > (table.table-editor + .table-row-btn + .table-col-btn)，单元格内含 .table-cell-wrapper，表头行挂 .table-col-drag-handle、首列挂 .table-row-drag-handle（grip 图标，hover 显形）。右键手柄弹 core/menu 的行/列/对齐/排序菜单；增删行列、移动、复制、对齐、排序全部经 table-model 改写整块 Markdown 文本，加号按钮插到末尾行/列，最后一行或列被删除时移除整块表格；appendTableMenuItems 产出原版无选区表格菜单的 Row/Column 子菜单与两个排序项（section table/table-sort），installCellMenuHook 订阅 editor-menu 事件把同一套子菜单追加到原位编辑器的文本菜单末尾（原版 iZ.onMenu），每个 app 只订阅一次。删行路径带 blankEdges：原版 deleteSelection 在删首/末行时补 \n，这里只在相邻行有正文（空行会被吃掉）时补，已隔空行不叠加。setActiveDragHandles/unsetActiveDragHandles 给编辑中的行、列首格打 mod-active-* 类并给容器打 has-focus（原版 editTableCell/destroyTableCell），触屏下据此常显手柄；首次渲染按 (hover: none) 给 body 打 is-touch。点击单元格把光标落到对应源码行，部件让位给原始 Markdown（T0 验收锁定）。跨重建的选区与换格焦点经模块级 carriedState 交接给新实例（原版 render() 末尾重放 selectionAnchor/Head 的等价物）。
table-drag.js: 手柄拖拽重排。移植原版 createDragHandle 的 pointerdown 全流程：量取行/列箱体与手柄几何后起 rAF 帧循环，做滚动容器边缘自动滚动、手柄位移钳制、.table-drag-target.mod-row|mod-col 落点线定位；pointermove 额外同步更新一次落点（不依赖帧率）。pointerup 调 widget.moveRow/moveColumn 并选中落点行/列，Esc/pointercancel/contextmenu 取消，dragstart/drop 视为结束。
table-selection.js: 单元格矩形选区与剪贴板。移植原版 mq/gq 的 pointerdown 框选（closestCell 命中、is-selected/start/end/top/bottom/mod-dragging 类）与选区右键菜单（clipboard 剪切/复制/粘贴 → 对齐 → 清空/删除，去掉原版 formatting 子菜单）。无选区单元格右键（buildCellMenu）= clipboard 三项 + 文本格式子菜单 + Table 子菜单，与选区菜单互斥：命中选区走选区菜单，原位编辑器内的右键记录待追加目标（appendPendingTableMenu 给 table-widget 的 editor-menu 钩子用）。子表格载荷走 obsidian/table 的同进程缓存，系统剪贴板写 text/plain 与 text/html；纯文本同样留同进程副本——窗口未聚焦时 Chromium 拒绝系统剪贴板（NotAllowedError），写读都退回缓存 + document.execCommand 兜底，单元格剪切/复制因此作用于整格文本（编辑器选区 > DOM 选区 > 整格）。粘贴缺行补行、缺列补列。
table-edit.js: 单元格原位置编辑。textarea 编辑器替代原版单元格 CM 实例：进入即全选（Tab/Enter 换格）、blur 或 Enter/Tab 提交（trim + 换行落 <br> + 未转义 | 补反斜杠）、Esc 取消、Tab/Shift+Tab 逐格移动（末格在表尾加行、首格在表头前插行）、Enter 下移或末行加行、IME 合成期间挂起提交；进入调 widget.setActiveDragHandles、关闭调 unsetActiveDragHandles（原版 editTableCell/destroyTableCell 的手柄与 has-focus 语义）。
table-format.js: 单元格文本格式层（原版 NV 的 selection.format 段）。「文本格式」子菜单的条目、图标、section 对齐原版三段 selection.basic / selection.advanced / selection.danger（加粗/倾斜/删除线/高亮、代码/数学/注释、清除格式）；原版动作调单元格 CM 的 toggleMarkdownFormatting，这里改写单元格 Markdown：整格被标记包裹即勾选，包裹/去包裹按同一套标记（**、*、~~、==、`、$、%%），编辑器内有选区时只包裹选区。table-selection.js 的单元格菜单是唯一调用方。
folding.js: 标题与缩进范围按文档缓存。事务过滤禁止语法回退绕过设置。foldSelectionStep按选区逐层折叠或展开，保留其他分支的折叠。
completions.js: [[wikilink]] 补全数据层，不创建 DOM。buildLinkContext 识别同一行未闭合 [[；collectLinkSuggestions 覆盖文件/别名/未创建 linktext、本地或全局标题与块；文件建议保留完整路径，重复 basename 插入完整路径并补 |basename；buildLinkInsertion 生成 file/heading/block/display 四模式文本。
link-suggest.js: [[链接]] 单列浮窗。挂 body 的 .suggestion-container.link-suggest > .suggestion + .prompt-instructions，逐项对齐原版 EditorSuggest；空查询不预选，非空预选首项；上下/Page/Home/End/Ctrl+P/N、Enter/Tab/Shift+Enter、点击/悬停、Esc/失焦/外部点击/滚动/缩放；# 先接受文件再进标题，^ 进块，| 进显示文本；尺寸由内容收缩（max 500×300），不使用 CM autocompletion 或 .cm-completionInfo。
editor-commands.js: registerEditorCommands(app)。注册 editor:* 与 markdown:* 命令。换行复用CM6事务，整体移动选区并保留光标。含 set-heading-1..6/0（按行改写前缀）、toggle-blockquote、clear-formatting（选区去标记）、attach-file（选文件复制进库并插入嵌入）、download-attachments（画廊勾选下载外部图片并改写嵌入/frontmatter 链接）、paste（剪贴板图片优先，其次纯文本）。copy/cut/paste 文本走 Electron clipboard（菜单点击后编辑器失焦，execCommand 会空转）。
