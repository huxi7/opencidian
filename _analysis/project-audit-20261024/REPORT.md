# OpenSidian项目审查（2026-10-24）

基线a39bf9a。原版事实源为1.14.4静态包，不启动原版。
阶段：三线修复中。完成度结论在最终回归后填入。

## 审查范围

- 文件创建、回收站、移动、保存、多窗口与生命周期。
- Markdown/Canvas加载、编辑命令、设置能力与侧栏交互。
- Bases、搜索、书签、标签及核心插件启停。
- 全量隔离Electron、Node、工作区VM、目录包核对。
